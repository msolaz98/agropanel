Estación agroclimática

Cada vez que abres o recargas la página se descargan los datos de la estación seleccionada desde esta dirección. {codigo} se sustituye por el código SiAR (p. ej. V14). Con el script diario incluido, deja el valor por defecto.

Columnas reconocidas: fecha, tmax, tmin, tmed (o temperatura), humedad/HR, precipitación/lluvia, ETo (EtPMon), viento. Separador ; o , y decimales con coma o punto. También el JSON de la API SiAR.
